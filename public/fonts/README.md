# Fonts

What a carried-over resume is set in. `lib/resume/fonts.ts` maps the face
embedded in an uploaded PDF to one of these; the first group are metric twins
of the faces Word and Google Docs resumes are usually set in, so a line breaks
where it broke in the original.

Latin subsets, regular / italic / bold / bold italic, from
[Fontsource](https://fontsource.org). All are free to embed in a PDF.
